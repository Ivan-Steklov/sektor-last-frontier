# CONTEXT.md

## Проект

**Сектор: Последний Рубеж** — компактная асинхронная космическая стратегия для Telegram Mini App в духе OGame.

Текущий MVP делается вокруг одной домашней ��ланеты, серверных таймеров, очередей, флота, экспедиций и первых галактических миссий.

---

## Технологии

- Frontend: React + TypeScript + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Migrations: Alembic
- Tests: pytest
- Local DB: Docker Compose
- Repo: GitHub

---

## Архитектурный принцип

**Backend — источник истины.**

Frontend только:

- показывает состояние;
- отправляет команды;
- показывает клиентские таймеры;
- обновляет данные с backend.

Все важные расчёты выполняются на сервере:

- производство ресурсов;
- энергия;
- стоимость зданий;
- стоимость исследований;
- стоимость кораблей;
- завершение таймеров;
- очереди;
- списание ресурсов;
- результаты экспедиций;
- результаты галактических миссий;
- возврат/потери кораблей;
- награды миссий.

## Текущий игровой контур

Сейчас в игре реализовано:

### Планета и экономика

- пользователь по `telegram_id`;
- одна домашняя планета;
- ресурсы:
  - металл;
  - кристалл;
  - энергия;
  - население;
- серверный расчёт добычи по времени;
- склад;
- энергетика;
- синхронизация ресурсов перед важными действиями.

### Здания

Есть здания:

- `metal_mine`
- `crystal_mine`
- `power_plant`
- `warehouse`
- `shipyard`
- `research_center`
- `defense_module`

Реализовано:

- уровни зданий;
- стоимость улучшений;
- очередь строительства;
- один активный апгрейд на планету;
- серверный таймер;
- повышение уровня после завершения;
- защита от двойного старта;
- индекс:
  - `ix_building_queue_one_active_per_planet`

### Исследования

Реализовано:

- каталог исследований;
- уровни исследований;
- стоимость и время;
- одна очередь исследований;
- индекс:
  - `ix_research_queue_one_active_per_planet`
- требование:
  - чтобы исследовать уровень `N`, нужен `research_center >= N`
- исследования влияют на экономику:
  - `metal_mining`
  - `crystal_mining`
  - `energy`
- исследования влияют на экспедиции:
  - `engines`
  - `cargo`
  - `recon`

### Корабли

Есть первые корабли:

- `scout`
- `transport`
- `fighter`

Реализовано:

- состояния кораблей на планете;
- очередь производства кораблей;
- требования верфи;
- списание ресурсов;
- готовые корабли добавляются на планету.

### Экспедиции

Реализовано:

- одна активная экспедиция на планету;
- индекс:
  - `ix_expedition_one_active_per_planet`
- корабли снимаются с планеты при старте;
- после завершения сервер считает результат;
- возможные исходы:
  - пусто;
  - металл;
  - кристалл;
  - потери;
- выжившие возвращаются;
- результат последней экспедиции отображается.

### Галактика

Реализовано:

- первый сектор галактики вокруг домашней планеты;
- сектор рассчитывается детерминированно на backend;
- отдельные таблицы галактики минимальны, без полной карты мира;
- есть экран галактики на frontend.

### Разведка систем

Реализовано:

- первая галактическая миссия: разведка системы;
- нужен `1 scout`;
- разведчик убирается с планеты на время миссии;
- после завершения возвращается;
- создаётся серверный отчёт разведки;
- разведанные системы сохраняются в БД;
- разведанные системы помечаются на карте;
- повторная разведка обновляет сохранённый отчёт.

### Добывающие миссии в галактике

Реализовано:

- отправка `1 transport` в уже разведанную систему;
- одна активная добывающая миссия на планету;
- транспорт снимается на время миссии;
- после завершения:
  - транспорт может вернуться или погибнуть;
  - начисляются металл/кристалл;
  - сохраняется последний результат;
- опасность системы влияет на исход:
  - низкая — безопасно;
  - средняя — потеря части груза;
  - высокая — возможна потеря транспорта и груза;
- старые payload добывающих миссий нормализуются при чтении.
